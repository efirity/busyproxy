# Archived IPAs (optional)

Place exported App Store / TestFlight IPAs here if you want a local archive.

```text
BusyProxy-1.0.0-1.ipa
```

Binaries are gitignored by default (`*.ipa`) unless you force-add under this folder
(same pattern as `google-play/releases/*.aab`). Prefer re-building with Fastlane
on the Mac host rather than committing large IPAs.
